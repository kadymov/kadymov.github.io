# Skin / hand — GitHub Pages

Готовый статический сайт. Backend, Python, Node.js, установка пакетов, API-ключи, туннели и сборка для работы сайта не нужны. HTML, JS, модель, шейдеры и веса загружаются обычными статическими файлами. Обработка происходит в браузере посетителя.

## Размещение

### Если github.io уже работает

Скопируйте содержимое этой папки в отдельную папку `skin/` внутри публикуемой части своего репозитория. Существующий index.html сайта заменять не нужно. Адрес будет вида `https://<user>.github.io/skin/` (либо `https://<user>.github.io/<repo>/skin/` для project Pages).

### Для отдельного репозитория

1. Поместите **содержимое** этой папки в корень выбранного репозитория; сохраните вложенную структуру `assets/`, `vendor/`, `weights/` и файл `.nojekyll`.
2. В Settings → Pages выберите **Deploy from a branch**, нужную ветку и **/(root)**.
3. После публикации откройте HTTPS-адрес, показанный GitHub. Для project Pages это `https://<user>.github.io/<repo>/`.

Можно использовать `/docs`, если эта папка выбрана в настройках Pages. Пути вычисляются относительно модулей и страницы, поэтому сайт работает и в корне, и во вложенном пути. Загрузка новых файлов в GitHub этой задачей не выполнялась.

[Настройка Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https)

## iPhone 15

По умолчанию выбрано **512×512**. В «Параметрах» доступны **320×320** (быстрее), **512×512** (баланс), **768×768** (чётче, больше памяти); выбор сохраняется в браузере. Он определяет размер кадра и для three.js, и для DLSS. На телефоне — текстуры **2K**, тени **1024×1024**, DPR=1; на настольном экране используются те же 2K-текстуры. Для проверки мобильного профиля на компьютере добавьте `?profile=phone` к адресу.

- Один палец вращает руку, два приближают; ↺ возвращает камеру.
- DLSS и «Рассеивание» выбирают сравнение; кнопка запускает обработку, ползунок раскрывает до/после.
- Нейросеть загружается **только по кнопке**, 141 MiB при первом запуске. Автоматическое сравнение после остановки выключено; включается в свёрнутых «Параметрах».
- Смена разрешения освобождает старые буферы сцены и DLSS; загруженные веса сохраняются. Выбор временно заблокирован во время обработки.
- В геометрических проходах включено 4× MSAA (либо 2× на поддерживаемом GPU). Цвет на частично покрытых пикселях компонуется с учётом покрытия; это сглаживает края без затемнения контура.
- При движении старое сравнение скрывается; устаревший результат отбрасывается. В покое сцена не рисуется непрерывно, фоновая вкладка приостанавливает отрисовку и таймер.
- Для DLSS на iPhone нужен **Safari на iOS 26+**, WebGPU, shader-f16 и минимум 32 KiB workgroup storage. GPU проверяется до загрузки весов. При отсутствии поддержки доступны рука и SSS.

Физический iPhone 15 пока не проверен. 191 MiB активаций и 144 MiB весов GPU измерены при 320×320 на настольном Apple GPU; это не замер скорости или памяти Safari на телефоне.

## Файлы и веса

Модель кисти занимает 6240976 байт. Общий размер сайта около 155 МБ. Все файлы не больше 16 MiB: крупнейшая стадия сети разделена на части; браузер собирает их в исходный массив без изменения тензоров. Это укладывается и в лимит 25 MiB для отдельного файла при загрузке через веб-интерфейс GitHub. Git LFS не нужен.

`weights/manifest.json` содержит длины и SHA-256 стадий и частей. Все стадии после сборки побайтово соответствуют извлечённым исходным весам 310.8.0. Изменены только загрузчик частей и пути ресурсов; шейдеры и вычислительный граф не менялись. Хеши локальных адаптаций: `vendor/opendlss/PROVENANCE.json`.

## Материал и ограничения

Скан [Female hand](https://sketchfab.com/3d-models/female-hand-3e9b8ad1942048e3a267d92fb1124d46) by deep3dstudio, **CC BY-NC 4.0**: только некоммерческое использование с атрибуцией. 8082 треугольника, 4390 вершин. Встроенные карты уменьшены до 2K, геометрия сохранена. Glossiness из альфа-канала преобразуется в roughness, RGB specular — в отражение физического материала. Масштаб нормализован примерно до 25 см.

SSS — экранное приближение диффузии с сохранением бликов, без объёмного просвечивания пальцев. DLSS обрабатывает один неподвижный линейный HDR-кадр; история сбрасывается, векторы движения нулевые. Нейросеть может менять цвет и детали. RGB-отличие в диагностике не является метрикой качества; совпадение с официальным NVIDIA runtime не установлено.

three.js и OpenDLSS-NR — MIT, см. THIRD_PARTY_NOTICES.md. Веса NVIDIA — отдельные проприетарные данные и **не входят в MIT-лицензию**. Право на их публичное распространение этой задачей не установлено. Локальная упаковка не означает публикацию или предоставление такого права.
